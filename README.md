# Venin Games

وب‌سایت معرفی استودیوی بازی‌سازی ونین گیمز با صفحه‌های خانه، بازی‌ها، استودیو و تماس در دو زبان. نسخهٔ انگلیسی در ریشه و نسخهٔ فارسی با چیدمان راست‌به‌چپ در مسیر `/fa/` قرار دارد.

## پیش‌نمایش محلی

از پوشهٔ ریپو اجرا کنید.

```sh
python3 -m http.server 8000
```

نسخهٔ [انگلیسی](http://localhost:8000/) و [فارسی](http://localhost:8000/fa/) در مرورگر باز می‌شوند. سایت با HTML، CSS و جاوااسکریپت ساخته شده و فایل‌های تصویر و فونت را از خود ریپو می‌خواند.

## ویرایش و انتشار

- هر صفحه یک فایل `index.html` دارد. متن انگلیسی در `index.html` و پوشه‌های `games`، `studio` و `contact` است. متن فارسی در ساختار مشابه پوشهٔ `fa` قرار دارد.
- هنگام تغییر کانسپت‌های نمونه، کارت خانه و کارت همان بازی در صفحهٔ بازی‌ها را در هر دو زبان به‌روز کنید. جست‌وجو از عنوان، سبک و نام انگلیسی کارت استفاده می‌کند.
- رنگ‌ها و چیدمان در `assets/site.css` و رفتار منو، پنجرهٔ بازی، جست‌وجو، فرم و انیمیشن‌ها در `assets/site.js` هستند.
- فرم تماس پیش‌نویس قابل‌کپی می‌سازد و پیام را در برنامهٔ ایمیل باز می‌کند. برای تغییر مقصد فرم، لینک `data-contact-email` را در `contact/index.html` و `fa/contact/index.html` به‌روز کنید.
- فایل‌های سایت مستقیماً از ریشهٔ ریپو سرو می‌شوند. در تنظیمات GitHub Pages، شاخهٔ `main` و پوشهٔ `/ (root)` را به عنوان منبع انتخاب کنید.

تصاویر `assets/images` برای این سایت با ImageGen ساخته شده‌اند. مجوزهای فونت‌های Space Grotesk و Vazirmatn در `assets/fonts` قرار دارند.
